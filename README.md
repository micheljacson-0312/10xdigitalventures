# 10x Team Chat - Company WhatsApp

A robust, full-stack, cross-platform team chat system built for web, mobile, and desktop.

## Features
- Real-time Messaging
- Delivery/Read receipts
- Voice notes, and rich media
- Next.js 14 Web, Expo Mobile, and Electron Desktop
