## 2025-05-14 - Auto-resizing Message Input
**Learning:** Implementing auto-resizing for message input textareas significantly improves the 'mobile-app' feel and usability of desktop chat interfaces by maintaining visibility of context while accommodating longer messages. It also avoids awkward scrollbars within a small input area.
**Action:** Always consider auto-resizing for multi-line text inputs in chat or comment components to enhance the fluid feel of the UI.
